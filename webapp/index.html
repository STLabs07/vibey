Built for coding through an agent

When an AI writes the code, your job is to read, steer and approve. A bare terminal hides the files it's changing; a full IDE spends half a gigabyte on typing you no longer do. Vibey gives you the view and the terminals, and leaves the rest out.

Everything you need while the agent works

Every project in one window

Open three repos with three agents and they all live in one window. Each project keeps its own files, tabs and terminals. Switch from the rail or with Ctrl+1 to 9; no hunting through windows.

When Claude finishes in one project while you're in another, its avatar gets a dot, and next time Vibey reopens all of them where you left off.

vibey ~/storefront ~/billing-api ~/app

    Download for Linux 2.4 MB

    Free and open source. No account, and no network access: your code stays on your machine.

    1. Install the package

      sudo apt install ./vibey_0.1.0_amd64.deb

    2. Open a project

      vibey .
    Build from source instead

    Install Rust from rustup.rs and the build tools, then run the install script from the source folder.

    sudo apt install build-essential pkg-config libgtk-4-dev libvte-2.91-gtk4-dev
    scripts/install.sh
